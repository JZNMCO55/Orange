# 开发日志

## 2025-06-11


### 主要工作内容

**1. Logger系统架构重构**
- 将原有简单Logger.h/cpp从`Src/OrangeEngine/Layer1/Core/Debug/`移动到`Src/OrangeEngine/Layer1/Core/Base/`
- 实现双日志器系统：Core和Client分离的日志记录

**2. Memory系统错误修复和完善**
- 修复Memory.cpp中的C++14兼容性问题：替换`std::scoped_lock`为`std::lock_guard`
- 解决Tracy性能分析器集成的编译问题，添加条件编译保护
- 修正Logger宏调用格式，确保参数传递正确
- 完善内存分配器的线程安全机制
- 优化内存跟踪系统与Logger的集成

**3. Buffer系统实现**
- 实现通用内存缓冲区管理类Buffer，支持多种数据类型存储
- 提供BufferSafe类，具备RAII语义的自动内存管理
- 支持从STL容器（std::array、std::vector）直接构造缓冲区
- 实现类型安全的读写接口和边界检查机制
- 添加完整的Doxygen文档注释

**4. Profiler系统集成**
- 集成Tracy性能分析器，提供函数和作用域级别的性能跟踪
- 实现条件编译控制，在不同构建模式下自动优化性能开销
- 提供帧标记、函数分析、作用域分析和线程标记等功能
- 支持动态命名的性能分析作用域
- 在Distribution模式下完全禁用，实现零性能开销

**5. Logger核心功能实现**
- **日志级别系统**：Trace、Debug、Info、Warn、Error、Critical六个级别
- **标签化日志**：支持按标签分类的日志记录，预定义15个系统标签（Core、Memory、Renderer、Audio、Physics、Scripting、Asset、Scene、Animation、Input、Network、Platform、Timer、ThirdParty等）
- **TagDetails配置**：每个标签可独立配置启用状态和最低级别过滤
- **内存安全设计**：使用简单实现替代复杂的spdlog依赖，确保编译通过

**6. 宏接口系统**
- **核心日志宏**：`ORG_CORE_TRACE/DEBUG/INFO/WARN/ERROR/CRITICAL`
- **客户端日志宏**：`ORG_TRACE/DEBUG/INFO/WARN/ERROR/CRITICAL`
- **标签化日志宏**：`ORG_CORE_*_TAG`和`ORG_*_TAG`系列
- **条件编译优化**：Debug模式全启用，Release模式禁用Trace/Debug，Distribution模式只保留Critical

**7. 断言系统集成**
- 更新Assert.h以使用新的Logger API
- 支持`ORG_CORE_ASSERT/ORG_ASSERT`和`ORG_CORE_VERIFY/ORG_VERIFY`
- 集成Windows平台MessageBox显示

**8. 文档完善**
- 添加完整的Doxygen注释（@file、@brief、@details、@param、@return等）
- 类和函数的详细说明
- 使用示例代码块
- 分组文档（@defgroup、@{、@}）

- **线程安全**：内存分配和日志记录的并发安全
