## 缺口（本 spec 要补，全在 OrangeEngine 子仓）

编辑器侧三件，按优先级：

1. **AnimatorComponent 可挂 "clip" backend**（当前完全不 Addable）。
2. **Inspector 引用 / 重指派 `.anim` 资产**（AssetRef 字段）+ **播放控制**（Play/Pause/loop）。
3. **（后续大件）timeline / dopesheet / 曲线编辑器**（B2.3/B2.4，本 spec 不展开）。

## 改点 1：ClipAnimator 记住来源 .anim 路径（引擎层，前置）—— ✅ 已落地（OE `34bc312`）

> **2026-06-02 已实现**：ClipAnimator 加 `mSourceAssetPath` + Set/Get；WriteAnimator
> 二选一写 clipSource(引用)/clipJson(内联)；SceneSerialization clip 分支有 clipSource +
> assetRegistry → `Load<AnimationClip>` + Get + SetSourceAssetPath，否则走 clipJson。
> 零回归（内联 clip 仍走 clipJson）。`TestClipAnimatorAssetSourceRoundTrip` 锁住。
> 下面是当时的设计说明（与实现一致），保留供改点 3 的 Inspector get/set 桥接参考。

**现状**：`ClipAnimator` 按值持 `AnimationClip mClip`，**不记**它来自哪个 `.anim`。Inspector
要显示 / 重指派 clip 资产就需要一个稳定的来源标识。

**改**（`include/orange/engine/animation/ClipAnimator.h` + `.cpp`）：
- 加 `std::string mSourceAssetPath`（空 = 内联构造、非来自资产，如 demo）。
- 加 `void SetSourceAssetPath(std::string_view)` / `std::string_view SourceAssetPath() const`。
- **序列化扩展**（`ComponentSerializers.cpp::WriteAnimator` + `SceneSerialization.cpp` clip 分支）：
  - Save：若 `SourceAssetPath()` 非空，写 `clipSource` 字段（path），**不再**嵌 clipJson（资产化的 clip 由资产文件持有，scene 只存引用，避免双源真相）；为空才走现有 clipJson 内联嵌入（兼容 demo / 程序化 clip）。
  - Load clip 分支：若有 `clipSource`，`AssetRegistry::Load<AnimationClip>(clipSource)` + `Get` 拷进 ClipAnimator + `SetSourceAssetPath`；否则走现有 clipJson 内联重建。需要 `LoadOptions` 带 `assetRegistry`（已有，RenderableComponent.mesh 同款）。
- **零回归**：现有 "clip" backend 实体（demo、`TestClipAnimatorRoundTrip`）`SourceAssetPath` 为空 → 仍走 clipJson 路径，字节与行为不变。新增 clipSource 是 minor 兼容扩展（旧 scene 无此字段 → 走 clipJson 分支）。

## 改点 2：AssetKind::AnimationClip（编辑器 schema 层）

**`tools/OrangeEditor/schema/PropertyType.h:98` `enum class AssetKind`**：加
```cpp
AnimationClip,  // .anim → AssetHandle<AnimationClip>
```
- DnD payload / Asset 浏览器过滤按 `.anim` 后缀映射到本 kind（参 Material 的 `.material` 后缀判定，PropertyType.h:97 注释）。
- Asset 浏览器需认 `.anim` 为可浏览资产类型（找 AssetBrowser 的扩展名→kind 表，与 `.material`/`.mesh` 同处登记）。

## 改点 3：RegisterAnimatorComponentSchema 加 clip 字段 + 播放控制

**`tools/OrangeEditor/schema/RegisterBuiltinSchemas.cpp:1018 RegisterAnimatorComponentSchema()`**
当前仅 `FieldCustom<std::string>("backend", ...).ReadOnly()`。扩展（**仅当 backend=="clip" 时**
这些字段有意义——用 `visibleIf` 门控，参 Collider 的 shape visibleIf 互斥段）：

- **`FieldAssetRef("clip", "Clip", AssetKind::AnimationClip, clipGet, clipSet)`**：
  - `clipGet(const void* c, void* outPath)`：`ac->animator` 且 `BackendName()=="clip"` →
    `static_cast<ClipAnimator*>(...)->SourceAssetPath()` 写出；否则空串。
  - `clipSet(void* c, const void* inPath)`：解析新 path → `AssetRegistry::Load<AnimationClip>` →
    `Get` → `ClipAnimator::SetClip(*loaded)` + `SetSourceAssetPath(path)`。需 `EditorAssetContext`
    （AssetRef 字段的 ctx 走 ADR-004 方案 B 的 `AssetRefGetFn/SetFn` 专用槽，RegisterBuiltinSchemas.cpp:335 注释）。命令栈：clip 重指派应可 Undo（CaptureComponentState 需认 ClipAnimator 的 clip+path，参 AssetRefArray 的 capture 分支 RegisterBuiltinSchemas.cpp:468）。
- **loop checkbox**：`FieldCustom<bool>("loop", "Loop", loopGet, loopSet)` 桥接 `ClipAnimator::IsLooping()/SetLoop()`。
- **Play/Pause 按钮 + playhead scrub**（FieldCustom 渲一行 ImGui 按钮 + Seek slider）：Play→`anim->Play()`、Pause→`anim->Pause()`、scrub→`anim->Seek(t)`。**注意**：编辑器 Edit 模式不跑 `TickAnimators`，scrub 要直接调 `Seek`（内部 `ApplyPose`）才看得到；Play 按钮的"编辑期预览播放"需要 EditorRenderLayer 在 Edit 模式下对被预览 animator 单独 tick（**新机制，dogfood 重点**，避免和 PlayState::Play 的全量 tick 混淆）。

## 改点 4：AnimatorComponent "clip" backend 可 Addable

**现状**（RegisterBuiltinSchemas.cpp:1022-1026 注释）：AnimatorComponent 不 Addable，因为
`animator` 是抽象 `unique_ptr<IAnimator>`，schema 无"构造抽象子类"入口。

**改**：走 Renderable 的 **c10 自定义 add 路径**（RegisterBuiltinSchemas.cpp:355 提到的"Renderable
自定义 add 路径"）——"+Add Component" 菜单加一项 **"Animator (Clip)"**，其 add 回调：
```cpp
AnimatorComponent ac;
ac.animator = std::make_unique<ClipAnimator>(AnimationClip{}, world.GetComponent<TransformComponent>(e));
world.AddComponent(e, std::move(ac));
```
（空 clip + target=self Transform；用户随后在 Inspector 拖入 .anim 资产填充 clip。）
- Skeletal / Procedural backend 仍不 Addable（需 skeleton/channel 参数，不适合默认构造）——只开 "clip"。
- Removable：可开（删 AnimatorComponent 直接 erase；命令栈 capture 需认 ClipAnimator，同改点 3）。

## dogfood 计划（改点 3/4 落地后追加到 dogfood-checklist）

- +Add Component → "Animator (Clip)" → 实体得到空 ClipAnimator（Inspector backend=clip）。
- Asset 浏览器出现 `.anim` 卡片；拖进 Inspector 的 Clip 字段 → 字段显示路径。
- Play（编辑期预览 or PlayState::Play）→ 实体按 clip 动；loop 勾/取消生效；scrub playhead 实时跟随。
- Save → 重启 → Load → clip 引用还原（走 clipSource 路径，非内联嵌入），再 Play 行为一致。
- ⚠️ "编辑期预览播放"是新 tick 路径，重点验证它与 PlayState::Play 的全量 tick 不打架、Stop 后归位。
